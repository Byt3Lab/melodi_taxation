# MELODI Fiscalité & Taxes

Moteur fiscal, gestion des zones de taxation, taux de TVA et règles d'application fiscale.

## Informations du module

| Propriété | Valeur |
|---|---|
| Catégorie | finance |
| Version | 1.0.0 |

## Dépendances

- MELODI : `base`, `melodi_geo`
- Python : aucune

## Installation dans MELODI

Dans une copie de MELODI, ajoutez ce dépôt comme sous-module à `modules/melodi_taxation` :

```bash
git submodule add -f git@github.com:Byt3Lab/melodi_taxation.git modules/melodi_taxation
```

Si ce chemin contient déjà des fichiers, sauvegardez-les et déplacez-les avant d'ajouter le sous-module.
